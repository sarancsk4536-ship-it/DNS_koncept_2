# DNS DIY Catalog V18 — корректировка структуры «Резка твердых материалов»

## Что исправлено относительно V17

- Полностью удалён отдельный корневой блок `Работа по материалу`.
- Внутри `Электроинструменты` создан раздел `Резка твердых материалов`.
- Внутри раздела создан третий уровень: `Сталь`, `Бетон`, `Плитка`.

### Сталь
- Отрезные пилы
- Диски для отрезных пил
- Угловые шлифовальные машины (УШМ)
- Отрезные диски для УШМ

### Бетон
- Штроборезы
- Шлифмашины по бетону
- Угловые шлифовальные машины (УШМ)
- Алмазные диски
- Алмазные чашки
- Пылеулавливающие кожухи

### Плитка
- Плиткорезы
- Угловые шлифовальные машины (УШМ)
- Алмазные диски

## Дополнительные изменения

- Отрезные пилы и их диски перенесены из общего раздела электрических пил в `Резка твердых материалов > Сталь`.
- Штроборезы и шлифмашины по бетону находятся в `Резка твердых материалов > Бетон`.
- УШМ остаются доступными в основном шлифовальном разделе и дополнительно размещаются в соответствующих подуровнях резки твердых материалов.
- Предыдущие патчи V17 по `Смешиванию`, измерительным приборам и корректировке привязок сохранены.
