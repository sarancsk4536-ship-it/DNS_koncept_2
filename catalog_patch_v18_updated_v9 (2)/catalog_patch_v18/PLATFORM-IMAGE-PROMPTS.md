# Промты для генерации изображений аккумуляторных платформ

## Рекомендуемая концепция
- Использовать не просто логотип/название бренда, а карточку в стиле категории DNS.
- Формат: вертикальная карточка 4:5 или квадрат 1:1, высокое разрешение.
- Композиция: по центру 1 аккумулятор или аккумулятор + зарядное устройство, вокруг 5–8 характерных инструментов данной платформы полукругом/кольцом.
- Фон: белый или очень светло-серый, чистый, без лишнего декора.
- Стиль: реалистичный каталожный рендер / clean product hero.
- Текст внутри изображения лучше не добавлять: название платформы уже отображается подписью карточки на сайте.
- Важно: оставить достаточно воздуха по краям, чтобы карточка хорошо смотрелась в плитке.

## Базовый шаблон
```
Создай чистое каталожное изображение для карточки раздела интернет-магазина. Покажи аккумуляторную платформу [НАЗВАНИЕ ПЛАТФОРМЫ] бренда [БРЕНД]. В центре размести аккумулятор и при необходимости зарядное устройство, вокруг полукругом или кольцом расположи 6–8 инструментов этой платформы. Покажи только характерные инструменты платформы: дрель-шуруповерт, УШМ, циркулярная пила, лобзик, сабельная пила, фонарь, воздуходувка, садовый инструмент и другие релевантные позиции. Стиль — реалистичный каталожный рендер, аккуратная предметная композиция, белый или очень светло-серый фон, мягкие тени, без лишнего текста, без людей, без интерьера. Изображение должно хорошо читаться в формате плитки категории на сайте.
```
