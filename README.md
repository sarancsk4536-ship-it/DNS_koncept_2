# DNS DIY Catalog V16

Самый простой запуск: откройте файл `OPEN-SITE.html` двойным щелчком.

Вариант с локальным сервером: откройте терминал в этой папке и выполните `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000`.

После изменения исходных файлов пересоберите автономную версию командой `node build-open-site.mjs`.

Промты для подготовки фотографий карточек находятся в файле `IMAGE-GENERATION-PROMPTS.md`.

Расчёт объёма и план производства находятся в `IMAGE-PRODUCTION-PLAN.md`. Актуальные промты первого этапа в формате товарных фотографий DNS находятся в `PHASE-01-IMAGE-PROMPTS.md`.

Фотографии главного экрана подключены из `assets/generated/phase-01/`.

Карточки раздела «Подбор по этапам работ» используют оптимизированные WebP-фотографии из `assets/generated/stages/`: отдельные изображения добавлены для этапов и видов работ без создания лишних промежуточных уровней.
